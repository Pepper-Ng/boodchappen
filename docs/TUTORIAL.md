# User Tutorial

## 1) Register / Login
1. Open app.
2. Click **Login**.
3. Enter email/password. First time auto-registers.

## 2) Import recipe from AH
1. Go to **Recepten / Recipes** tab.
2. Paste AH Allerhande URL.
3. Click **Import**.
4. Click **Load** to view imported recipes.

## 3) Add to week menu
1. Open **Week menu**.
2. Choose recipe, day, and persons.
3. Click **Add**.

## 4) Generate grocery list
1. Open **Grocery list**.
2. Click **Generate**.
3. Combined ingredient quantities are shown.
